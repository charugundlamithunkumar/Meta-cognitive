## Confirmatory estimands and decisions

C-HF exactly repeats the original HF analysis on new paired trajectories:
P=conf(S0)−conf(L0), D=minus the confidence OLS slope over error doses
0,.25,.50,.75, endpoint L0−L100 descriptive. Ten points remains the practical
threshold. Use the same four-test Holm family, interval conditions,
equivalence band ±10 and whole-trajectory 10,000 bootstrap resamples, seed 0.
Report the registered classification length-driven, error-sensitive, mixed or
inconclusive. A different classification does not justify changing the rule.

C-HG exactly repeats HG1 R_C−R_B>0; HG2 R_C−R_A equivalent within ±5;
HG3 F_A−F_C>10; HG4 R_C−F_C>10. Use the original centered-bootstrap p-values,
10,000 paired resamples, 95% intervals, 90% equivalence interval, seed 0 and
the separate four-test Holm family at .05. All four must pass for the joint
recovery/underconfidence claim. If A or C overall accuracy is ≤5%, withhold
that verdict as floor-limited. Preserve opposite-signed and null effects.

These are two separately specified four-test families, as before; no new
omnibus claim or pooled main+C decision is introduced. Report main and C
estimates separately. Any pooled estimate is exploratory and labeled so.
Do not declare replication merely from non-significance. Prior main outcomes
are not used as confirmation observations or to choose an arm/checkpoint subset.

The secondary calibration, awareness and strict checkpoint/offset AUROC
analyses are unchanged. Distinguish global correctness and local numeric
slips, use common observations and ≥15 per class, and report undefined cells.
Secondary outcomes cannot rescue a failed primary decision.

## Completeness, provenance and stopping

Require all 32 paired trajectories and all allocated conditions. Main C has
2,464 checkpoint conditions / 24,640 task answers, excluding probes. M is
1,568 / 15,680; MR is 896 / 8,960. No significance-based stopping or sample
size adaptation. Retain every raw invalid output and use the original
missingness rules. Mock outputs never receive a scientific verdict.

Checkpoint atomically and resume only matching sample/source/config/model/
resource/registration fingerprints. Record the registration commit, source
snapshot, sample hashes, model/data manifest, GPU/driver, timings, arm order
and outputs. Reject changed/corrupt inputs rather than silently regenerate
committed answers. Refuse overwrite of existing analyses or archives.

N=32 is fixed as a direct repetition of the original study, reviewed using
the previously recorded eight-trajectory calibration residual simulations and
doubled-residual-scale (fourfold-variance) sensitivity. Those small-pilot estimates are uncertain and
do not guarantee equivalence precision or joint HG power. Do not increase N
or relax a margin in response to the main study's null HG tests.
